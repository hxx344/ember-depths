# 余烬地牢 · Ember Depths

纯代码编写的 3D 肉鸽（roguelike）射击游戏：单个 `index.html`，没有任何图片、模型或音频素材。几何体、材质、粒子和音效都在运行时用代码生成（Three.js r128 + WebAudio）。Three.js 已内嵌在 `index.html` 里，断网也能运行。

在线游玩：<https://hxx344.github.io/ember-depths/>

## 画面

- 地面石板和墙体砌石的贴图（颜色、法线、粗糙度）在启动时用噪声函数烘焙，没有图片文件。
- 后处理包含泛光、调色、暗角和胶片颗粒，需要 WebGL2。帧率持续过低时会自动关闭。
- 触屏设备自动降低分辨率、阴影和贴图精度。

## 运行

电脑上直接用浏览器打开 `index.html`，或在本目录起一个本地静态服务。手机上请用上面的在线地址：微信等应用里的文件预览不执行脚本，点击开始不会有反应。

```bash
python3 -m http.server 8000 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8000/
```

## 玩法

- 每层是随机生成的房间树。进入房间后房门落锁，清光所有波次才会打开。
- 击杀掉落余烬，升级时三选一强化；宝物房的祭坛和层底守卫掉落稀有遗物的几率更高。
- 18 种可叠加的强化：分焰、贯穿、反弹、追踪、爆裂、连锁电弧、霜蚀、护身火环、饮血等，可以组合出不同流派。
- 敌人按层数逐步解锁：史莱姆、法师、冲锋兽、炮塔、爆虫（贴脸自爆，地面预警）、分裂体、狙击眼（激光瞄准后高速射击）、炮手（抛射炮弹，落点预警）。同一种敌人在更深的层会学会新招式，例如法师连射和追踪法球、炮塔旋转扫射、冲锋兽二段冲锋和撞墙弹环。
- 第 4 层起出现精英怪：带金色光环，血更厚，死亡时释放弹环。
- 每层尽头有守卫，4 种轮换，半血后狂暴。基础招式有螺旋弹幕、弹环、冲撞和召唤，霰弹、陨石雨、旋转光束随层数解锁。每种守卫有一个更常用的招牌招式。击败守卫后走进传送门进入下一层。
- 难度曲线：前两层敌弹更慢、攻击间隔更长、敌人更少更脆，受伤后的无敌时间也更长。从第 3 层开始，弹速、射速、血量、波次和弹幕密度逐层上升。进入新的一层时会提示新出现的威胁。
- 一局一命，最佳记录存在浏览器本地。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| 鼠标 + 按住左键 | 瞄准并施放火弹（方向键也可以射击） |
| 空格 / Shift / 右键 | 冲刺（冲刺中无敌） |
| F | 切换自动瞄准（带弹道预判） |
| Esc / P | 暂停 |
| M | 静音 |
| 1 / 2 / 3 | 选择强化 |

触屏：左半屏拖动摇杆移动，自动瞄准射击，右下角按钮冲刺。
