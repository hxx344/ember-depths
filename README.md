# 余烬地牢 · Ember Depths

纯代码编写的 3D 肉鸽（roguelike）射击游戏：单个 `index.html`，没有任何图片、模型或音频素材。几何体、材质、粒子和音效都在运行时用代码生成（Three.js r128 + WebAudio）。Three.js 已内嵌在 `index.html` 里，断网也能运行。

## 运行

直接用浏览器打开 `index.html`，或在本目录起一个本地静态服务：

```bash
python3 -m http.server 8000 --bind 127.0.0.1
# 浏览器访问 http://127.0.0.1:8000/
```

## 玩法

- 每层是随机生成的房间树。进入房间后房门落锁，清光所有波次才会打开。
- 击杀掉落余烬，升级时三选一强化；宝物房的祭坛和层底守卫掉落稀有遗物的几率更高。
- 18 种可叠加的强化：分焰、贯穿、反弹、追踪、爆裂、连锁电弧、霜蚀、护身火环、饮血等，可以组合出不同流派。
- 每层尽头有守卫（4 种轮换，每种有螺旋弹幕、弹环、冲撞、召唤四种招式，半血后狂暴）。击败后走进传送门进入下一层，难度随层数上升。
- 一局一命，最佳记录存在浏览器本地。

## 操作

| 按键 | 作用 |
| --- | --- |
| WASD | 移动 |
| 鼠标 + 按住左键 | 瞄准并施放火弹（方向键也可以射击） |
| 空格 / Shift / 右键 | 冲刺（冲刺中无敌） |
| F | 切换自动瞄准（带弹道预判） |
| Esc / P | 暂停 |
| M | 静音 |
| 1 / 2 / 3 | 选择强化 |

触屏：左半屏拖动摇杆移动，自动瞄准射击，右下角按钮冲刺。
